## Image Guidelines

### File Format
- Use JPEG for photographs
- Use PNG for logos and images with transparency
- Use WebP for better compression (optional)

### Image Optimization
- Compress images to reduce file size
- Use appropriate dimensions (don't use larger images than needed)
- Maintain good quality while optimizing file size
- Consider using responsive images with srcset

### Alt Text
- All images should have descriptive alt text for accessibility
- Alt text should describe the image content for screen readers
- For decorative images, use empty alt attributes

## Custom Branding

When creating custom images for BAYTUL HIDAYA:

1. **Logo**: Use the specified colors (#c4f2de, #f2e2bd)
2. **Consistency**: Maintain consistent styling across all images
3. **Quality**: Use high-resolution images for professional appearance
4. **Relevance**: Ensure images are relevant to Islamic education and Quran learning
5. **Cultural Sensitivity**: Use appropriate imagery that respects Islamic values

## Image Naming Convention

- Use lowercase letters
- Use hyphens instead of spaces
- Be descriptive but concise
- Example: `quran-foundation-course.jpg` instead of `Quran Foundation Course Pic.jpg`
